Qqun qui n'a pas le backend installer peut juste faire:

cd backend
npm install

cela va aller lire tout le spackages dans packages.json puis installer ceux qui ne sont pas déjas installés

class validator
$ npm i --save class-validator class-transformer

bibliothèque officielle de NestJS pour gérer les JSON Web Tokens (JWT).
npm i --save @nestjs/jwt installer

// POUR LE TOKEN (JWT)
npm install --save passport-jwt
npm install --save-dev @types/passport-jwt

//C'est l'outil spécifique qui sait lire les jetons de tes utilisateurs.
npm install @nestjs/passport passport passport-jwt

npm install -D @types/passport @types/passport-jwt

//argon
npm install argon2

//pour Gmail SMTP
npm install nodemailer
npm install -D @types/nodemailer
//Pour Sécurité
npm install helmet

//Pour Swagger documentation API
npm install Swagger

//pour resend
 npm install resend

//pas encore utiliser
$ npm i bcrypt
$ npm i -D @types/bcrypt


npm i @nestjs/mapped-types
